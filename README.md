# بوت مراقبة حصص Net Academy 🎾

بوت تيليقرام يراقب صفحة الحجز
https://netacademy.sa/book?activity=tennis&type=trainer
ويرسل لك تنبيه أول ما تنزل حصص جديدة للمدرب **محمد الداعج**.

## طريقة العمل
1. يفتح الصفحة في متصفح حقيقي بدون واجهة (Playwright) عشان يشتغل حتى لو الموقع مبني بـ JavaScript.
2. يقرأ ردود الـ API (JSON) اللي يحمّلها الموقع ويدوّر على الحصص المرتبطة باسم المدرب،
   ولو ما لقى شيء يقرأ نص الصفحة نفسها ويطلع الأوقات القريبة من اسم المدرب.
3. يقارن بالفحص السابق، ويرسل رسالة فيها **الحصص الجديدة فقط** مع رابط الحجز.

## 1) إنشاء البوت
1. افتح [@BotFather](https://t.me/BotFather) وأرسل `/newbot` وخذ الـ **Token**.
2. أرسل أي رسالة للبوت الجديد، ثم افتح
   `https://api.telegram.org/bot<TOKEN>/getUpdates` وخذ قيمة `chat.id` (هذا الـ **Chat ID**).

## 2) التشغيل على جهازك أو سيرفر (فحص كل 5 دقايق + أوامر)
```bash
pip install -r requirements.txt
python -m playwright install --with-deps chromium
cp .env.example .env      # وحط فيه TELEGRAM_BOT_TOKEN
python bot.py
```
بعدها أرسل للبوت `/start` وبيشتغل. الأوامر:

| الأمر | الوظيفة |
|---|---|
| `/start` | الاشتراك في التنبيهات |
| `/check` | فحص الآن |
| `/status` | آخر نتيجة فحص |
| `/stop` | إيقاف التنبيهات |

## ▶️ التشغيل التلقائي (ويندوز)
- `run_bot.bat`: اضغطه مرتين ويشغّل البوت، ولو طفى (انقطع النت مثلاً) يرجّعه لحاله بعد 30 ثانية.
- `install_startup.bat`: اضغطه مرة وحدة عشان البوت يشتغل لحاله (مصغّر) كل ما تدخل الويندوز.
- `remove_startup.bat`: يلغي التشغيل التلقائي.
- `install_boot_task.bat` (زر يمين ← Run as administrator): يشغّل البوت **مخفي في الخلفية أول ما يشتغل الكمبيوتر**،
  حتى قبل تسجيل الدخول (مثلاً بعد إعادة تشغيل تحديثات ويندوز بالليل). ما يحتاج كلمة سر (يشتغل باسم حساب النظام SYSTEM).
- `remove_boot_task.bat` (Run as administrator): يوقف البوت المخفي ويلغي تشغيله مع الجهاز.

البوت ما يشتغل منه إلا نسخة وحدة، فلو فتحته مرتين الثانية تطلع لحالها.

## 🎫 الحجز بضغطة زر
التنبيه يجيك مع أزرار فيها الأوقات. تضغط على الوقت، والبوت يحجزه كضيف ببياناتك ويرسل لك **رابط الدفع**
تكمل منه من جوالك.

1. علّم البوت خطوات الحجز مرة وحدة: `py -3.13 bot.py --record`، واحجز في النافذة كضيف لين صفحة الدفع (بدون دفع)، وبعدها اقفلها.
   البوت يحفظ الخطوات في `booking_template.json`.
2. عبّ `GUEST_NAME` و`GUEST_PHONE` و`GUEST_EMAIL` في `.env`، وحط `TELEGRAM_CHAT_ID` عشان محد غيرك يقدر يستخدم الأزرار.
3. للتجربة: `py -3.13 bot.py --test-book` يعرض الطلب اللي بيرسله، ويحجز أول حصة متاحة بعد ما تكتب `yes` (حجز حقيقي غير مدفوع).

لو الموقع تحدّث وتغيّرت خطوات الحجز، البوت يقول لك تعيد `--record`.

## ⚠️ شغّله من إنترنت البيت
موقع الأكاديمية محمي بـ Vercel Security Checkpoint، وهذا يحجب الطلبات الآلية من السيرفرات ومراكز البيانات
(GitHub Actions والاستضافات السحابية). عشان كذا شغّل البوت على كمبيوترك أو أي جهاز على إنترنت البيت.
لو الموقع رفض الفحص (429)، البوت يبطّئ تلقائياً (`RATE_LIMIT_BACKOFF` ثانية) وينبهك بعد 3 محاولات فاشلة.

## كيف يقرأ البوت الحصص؟ ⭐
موقع الأكاديمية مبني بـ Next.js ويجيب أوقات كل يوم عن طريق "Server Action".
البوت يكتشف هذا الطلب تلقائياً من الصفحة (ويحفظه في `action.json`)، وبعدها يطلب
أوقات كل يوم من اليوم إلى `DAYS_AHEAD` يوم قدام مباشرة بدون متصفح، وينبهك لو ظهر المدرب في أي يوم.
لو الموقع تحدّث وتغيّر الطلب، البوت يعيد اكتشافه تلقائياً، ولو فشل كل شيء يرجع لطريقة المتصفح.

الأكاديمية تنزّل الحصص كل ليلة الساعة 12 ليومين قدام، فالبوت يفحص كل 10 ثواني من 11:58 إلى 12:15 بالليل،
وكل دقيقتين في باقي اليوم عشان يلقط الإلغاءات (`RELEASE_TIME` و`FAST_CHECK_INTERVAL` في `.env`).
⚠️ خلّ الكمبيوتر ما ينام (Sleep) بالليل وإلا ما بيفحص.

للتجربة: `python bot.py --probe` يطبع المدربين المتاحين في كل يوم (★ = المدرب المطلوب موجود).

## وضع API مخصص (اختياري)
بدل ما يفتح البوت متصفح كل مرة، يكلم رابط البيانات حق الموقع مباشرة:
```bash
python bot.py --find-api
```
يفتح صفحة الحجز ويطبع طلبات البيانات اللي فيها اسم المدرب (معلّمة بـ ★) مع سطور جاهزة تنسخها لـ `.env`.
لو الرابط فيه تاريخ، بدّله بـ `{date}` والبوت بيفحص كل يوم من اليوم إلى `DAYS_AHEAD` يوم قدام.
في هذا الوضع تقدر تخلي `CHECK_INTERVAL=60` (فحص كل دقيقة)، ولو تعطّل الـ API يرجع تلقائياً لطريقة المتصفح.

## اختبار وضبط
```bash
python bot.py --dump
```
يفحص مرة وحدة ويطبع الحصص اللي لقاها، ويحفظ في مجلد `debug/`:
صورة للصفحة `page.png`، و`page.html`، وكل ردود الـ API في `responses.json`.
لو ما طلعت الحصص صح، افتح هذي الملفات وعدّل `TRAINER_KEYWORDS` في `.env`
(مثلاً لو الاسم مكتوب بالإنجليزي بشكل مختلف).

## الإعدادات (`.env`)
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `TRAINER_KEYWORDS` | `الداعج,داعج,daej,...` | كلمات التعرف على المدرب |
| `TRAINER_LABEL` | `محمد الداعج` | الاسم اللي يظهر في الرسائل |
| `CHECK_INTERVAL` | `300` | الفحص كل كم ثانية |
| `CLICK_TRAINER` | `1` | يضغط على اسم المدرب لو الأوقات ما تظهر إلا بعد اختياره |
| `TARGET_URL` | رابط صفحة الحجز | الصفحة المراقبة |
